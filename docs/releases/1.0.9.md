更轻：微信没变化时不再每分钟启动检查 / Lighter: no per-minute engine run while WeChat is unchanged

- 窗口开着时，每分钟一次的定时检查改为先比对微信安装包里几个关键文件的指纹（大小、修改时间、属主与权限等，读取不到 1 毫秒）；微信没有更新、没被打补丁或还原时，不再启动检查引擎。微信更新、打补丁、还原、重签或改权限都会改变指纹，照常立即完整检查；指纹覆盖不到的变化由每 30 分钟一次的完整检查兜底，也可以随时按 ⌘R 重新检查。
- 发布包剥离调试符号：下载包由 2.8 MB 降到约 2.4 MB，解压后由 7.0 MB 降到约 4.3 MB。
- 源码构建实测（Apple M4 / macOS 27.2，窗口打开、无操作）：200 秒空闲窗口内检查引擎启动 0 次（1.0.8 每分钟 1 次，每次约 1.4 秒、0.25 秒 CPU）；界面进程空闲 CPU 0.03%，空闲内存 35 MB 与 1.0.8 相同。按全天开着窗口折算，后台检查的 CPU 时间由每天约 6 分钟降到约 0.2 分钟。
- 防撤回、拦截自动更新与自动重打的行为不变；内嵌引擎仍为 111e3d4，与 1.0.8 相同。

While the window is open, the once-a-minute check now compares a fingerprint of a few key files in the WeChat bundle (size, modification time, owner and permissions; reading it takes under a millisecond) and starts the check engine only when something changed. Updating, patching, restoring, re-signing or changing permissions all change the fingerprint and trigger a full check right away; anything the fingerprint cannot see is covered by a full check every 30 minutes, and ⌘R rechecks at any time. Release builds now strip debug symbols: the download drops from 2.8 MB to about 2.4 MB, and the installed app from 7.0 MB to about 4.3 MB. Measured on a source build (Apple M4, macOS 27.2, window open and idle): the check engine started 0 times in a 200-second idle window (1.0.8 ran it once a minute, about 1.4 s and 0.25 s of CPU each); the interface process idles at 0.03% CPU and 35 MB of memory, unchanged from 1.0.8. With the window open all day, background check CPU time falls from about 6 minutes a day to about 0.2 minutes. Anti-recall, the update block and automatic re-patching behave as before; the bundled engine is still 111e3d4.
