截屏 / 录屏权限修复 / Screen capture permission fix

- 修复 #13：开启保护后微信提示「录屏权限未开启」，系统设置里开关明明是开的。原因是打补丁后要给微信重新签名，旧版每次签出的身份都随内容变化，系统之前记下的截屏、麦克风、摄像头授权就对不上了。
- 现在首次开启保护时，会在本机生成一个只用于给微信重新签名的固定身份（存在 `~/Library/Application Support/WeChatTweak/signing/`，不上传、不加入系统钥匙串搜索列表）。此后切换模式、微信升级后重新开启，微信的签名身份保持不变，授权不再失效。
- 升级后第一次重新开启保护时，签名身份会从旧的换成固定的，App 会清掉微信已失效的截屏、麦克风、摄像头授权；下次微信用到时按系统提示重新允许一次即可，之后不用再授权。
- 签名后会先试启动一次微信的可执行文件；如果系统不接受新身份，自动退回原来的签名方式，微信照常可用（此时重新打补丁后仍需重新授权）。复制诊断里的 Signature 一行会写明当前用的是哪种身份。
- 本版没有新增补丁点，支持的微信版本不变。

Fixes #13: after turning protection on, WeChat reported that screen recording was not allowed although the switch in System Settings was on. Patching requires re-signing WeChat, and earlier versions produced a signing identity that changed with the content, so the screen capture, microphone and camera grants that macOS had recorded no longer matched. The first time protection is turned on, the app now creates a fixed identity on this Mac that is used only to re-sign WeChat (kept in `~/Library/Application Support/WeChatTweak/signing/`, never uploaded, not added to the keychain search list). Switching modes or re-enabling after a WeChat update keeps the same identity, so grants stay valid. The first re-enable after upgrading moves WeChat from the old identity to the fixed one and clears its stale screen capture, microphone and camera grants; allow them once when WeChat next asks. After signing, WeChat's executables are test-launched; if macOS rejects the new identity the app falls back to the previous signing method and WeChat keeps working (grants then still need to be allowed again after re-patching). The Signature line in copied diagnostics names the identity in use. No patch locations or supported WeChat builds change in this release.

macOS 13+ · Apple Silicon + Intel · ad-hoc signed, without Apple Developer ID signing or notarization.
