配置、快捷键与更新检查 / Settings, shortcuts and update checks

- 应用菜单的「配置与更新…」提供防撤回提示方式、自动重打偏好、配置导出/导入和可选 iCloud 同步；微信路径、权限、登录项和操作记录不参与配置迁移。
- 重新检查默认使用应用内 ⌘R；可在设置中改为 ⇧⌘R 或 ⌥⌘R，或关闭并恢复，拒绝保留组合和菜单冲突。
- 检查更新与自动行为选项使用同一套窗口和命令入口；公开版继续从 GitHub 获取发行记录和下载入口。
- 主窗口的检查、开启、还原和两项功能独立说明保持不变；本版没有新增补丁点或改变引擎判决。
- 设置、快捷键、同步往返与错误恢复、更新检查和升级保留设置经隔离真实产品验收；iCloud 验证范围是本机隔离链路，未验证 Apple 服务器跨设备传输。

The app menu's Settings and Updates window now includes the anti-recall presentation preference, automatic reapply preference, configuration export/import and optional iCloud sync. WeChat paths, permissions, login items and operation history are excluded from migration. Refresh defaults to the in-app Command-R shortcut; choose Shift-Command-R or Option-Command-R, disable or restore it, with reserved combinations and menu conflicts rejected. Update checks and automatic behavior options share the native window and command entry points; the public app continues to use GitHub release records and downloads. The main check, enable and restore workflow and independent per-feature results are unchanged; this release adds no patch locations and does not change engine decisions. Isolated real-product checks cover settings, shortcuts, sync and error recovery, update checks and preservation during an upgrade. The iCloud evidence covers local isolated transport, not Apple server delivery between devices.

macOS 13+ · Apple Silicon + Intel · ad-hoc signed, without Apple Developer ID signing or notarization.
