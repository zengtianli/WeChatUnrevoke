## 发版途中改了两处发版工具

1. **打包参数**（`release.sh`）。第一次打包被清单门拒绝：这次构建所在的进程会被系统给每个产出文件打上 `com.apple.provenance` 扩展属性，`ditto --sequesterRsrc` 把它们存成 `__MACOSX/._*` 旁文件，包里多出 17 项。改为 `ditto --norsrc --noextattr`，包回到批准的 12 项；清单门本身没有放宽。解压后的副本通过 `codesign --verify --deep --strict` 和两种架构的启动门。这一次失败发生在任何对外动作之前，所以修完后整体重跑了发布入口。
2. **站点资源模块**（`scripts/build-site.py`）。发布后站点第一次上线停在 README 门（预期内：发布前 1.0.12 仍是当前版，README 的历史实测措辞只能发布后改）；改完再上线，又被 Lintel 规范检查拒绝 8 项——原先“当前版四项未测 + 历史实测”两个模块并列的版式不符合“资源模块只出现一次、数字与实测证据逐字一致”的规则（上一版是发布后装机重测、改回“当前发行版”才上线的，这次不装机，所以走到了这条分支）。现在只保留一个模块：数字仍是 1.0.12 (92) 的实测原样，数字上方写明测量版本、不代表当前公开下载 v1.0.13 (99)、v1.0.13 待测，并单列当前 ZIP 的大小。三项对应测试随之改写。
