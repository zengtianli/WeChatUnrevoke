第一次用？从这里开始

不用懂 GitHub。
照着这三步做就好。

先确认你使用的是 Mac，并且已经安装微信。整个过程不需要注册账号。

  1. 01

    下载，解压，放进「应用程序」

    点击本站的「免费下载 Mac 版」。打开「下载」文件夹，双击 WeChatUnrevoke-{{VERSION}}.zip 解压，把出现的 WeChatUnrevoke.app 拖到访达左边的「应用程序」。

    下载的 ZIP→WeChatUnrevoke.app→📁 应用程序

    升级旧版？先退出旧 app。旧名称是 Unrevoke 的，请把旧 app 移到废纸篓，再安装新版；原设置会保留。

  2. 02

    第一次打开，被 Mac 拦住了？

    这份免费发布的应用没有 Apple 开发者 ID 签名或公证。如果弹出「无法验证开发者」或「已损坏」，确认来自本页并已放入「应用程序」后，按下面做一次。

    展开：解除这份应用的下载隔离标记
    1. 按 ⌘ + 空格，输入「终端」，按回车打开。
    2. 点击下面「复制命令」，粘贴到终端，按回车。
    3. 回到「应用程序」，再次双击 WeChatUnrevoke。
    xattr -dr com.apple.quarantine /Applications/WeChatUnrevoke.app

    这条命令只移除 WeChatUnrevoke 的下载隔离标记，不关闭 SIP，也不关闭整个系统的安全检查。若提示找不到文件，先确认 app 已放到「应用程序」。

  3. 03

    退出微信，然后点击「开启防撤回」

    在微信菜单里选择「退出微信」（只关聊天窗口不等于退出）。打开 WeChatUnrevoke，保持「保留提示（推荐）」，点击「开启防撤回」。系统需要时会让你输入 Mac 管理员密码，不是微信密码。

    看到「正在重新签名」时请等待，不要退出。完成后展开「详情」，确认防撤回：已生效、签名权限：完整，再打开微信。

提示 XAppUpdateManager not found，怎么办？

这是部分旧微信（例如 build 269136）的更新模块与当前拦截规则不匹配，不是让你关闭 SIP。回到应用点击「仅开启防撤回…」，确认更新风险后继续，再检查「详情」里的防撤回和签名权限。上面第二段视频演示这个操作；演示使用 269627 副本，没有伪造 269136 的报错。

应用说微信还在运行，但我已经关掉窗口了。

点击屏幕顶部微信菜单，选择「退出微信」，或在微信里按 ⌘Q。回到 WeChatUnrevoke 点「重新检查」。关闭聊天窗口不等于退出微信。

我的 Mac／微信版本支持吗？

需要 macOS 15 或更新版本，安装包同时支持 Apple Silicon 和 Intel。微信补丁按具体构建号和架构适配，由应用自动检查。应用能运行，不代表每个微信版本都支持；看到「还没收录」时请等待适配，不要反复强行开启。

查询 macOS 版本：点屏幕左上角  →「关于本机」。

微信更新以后，还需要做什么？

再打开本应用检查一次。自动重打只有在曾完整保护成功、不需要密码、微信已退出等条件满足时才执行；其余情况只提醒。仅防撤回模式不会阻止自动更新。

群聊会显示「对方撤回了一条消息」吗？

目前群聊只保留消息，不显示撤回提示。私聊的「保留提示」模式会保留提示，但位置不保证紧贴原消息。「静默」模式则不显示提示。

怎样撤销？会上传我的聊天记录吗？

在应用右下角点「还原微信」，确认后等待完成。还原会撤销补丁，不是帮你找回过去被撤回的消息。工具不读取或上传聊天内容；联网用于获取 GitHub 上的补丁配置。

还是不行，怎么把问题反馈给维护者？
  1. 在应用中点「复制诊断报告」。
  2. 先粘贴到备忘录，删掉不想公开的个人路径。
  3. 点击下面的「提交问题」，登录 GitHub 后填入现象、操作步骤和诊断报告。GitHub 是这里的源码与问题反馈平台；下载和使用不需要 GitHub 账号。
